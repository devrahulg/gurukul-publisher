Privacy policy

Gurukul Publisher · Last updated 25 September 2026

Gurukul Publisher is an internal tool operated by the owner of theAIgurukul. It publishes theAIgurukul's own videos to theAIgurukul's own YouTube channels and Instagram accounts. It has no other users.

What the tool accesses

  • YouTube (YouTube API Services): permission to upload videos to, and read basic statistics (subscribers, views, video count) of, the channel owner's own channels.
  • Instagram (Instagram API): permission to publish Reels to, and read basic profile statistics (followers, post count) of, the owner's own Instagram accounts.
  • Video files: the owner's own episode videos, read from the owner's private Google Drive folder through a read-only service account that has been given access to that folder only.

What it stores

Access tokens are stored only as encrypted secrets in the tool's GitHub repository and are used only to publish scheduled posts and read the statistics above. The tool keeps a log of each scheduled post (time, caption, status and the link to the published video). It does not collect, store or process personal data about viewers or any other person.

Sharing

No data is sold or shared with third parties. Data is sent only to Google (YouTube) and Meta (Instagram) to carry out the uploads the owner scheduled.

Google and YouTube

This tool uses YouTube API Services. By using it you are subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time from Google account permissions. Revoking it stops the tool from reaching the channel. Stored tokens are deleted within 7 days of revocation or on request.

Instagram

Instagram access can be removed at any time in Instagram under Settings → Website permissions → Apps and websites.

Contact

Questions about this policy: send a message to @theai_gurukul on Instagram.
